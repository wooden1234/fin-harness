# 指数数据查询

- 仅通过 `iwencai.index.query` 查询指数事实。
- 区分指数名称、代码、交易日期和指标（点位、涨跌幅、成交量等）。
- 返回时保留数据日期和来源；没有数据就明确报告缺口。
