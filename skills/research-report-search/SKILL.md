# 研报搜索

- 仅通过 `iwencai.report.search` 检索研报元数据。
- 当前阶段只回答标题、摘要、发布时间、机构名称、评级/目标价和 URL/PDF 路径；未下载或解析 PDF 时不得声称读过全文。
- 需要内容解读时，先确认已有可访问的 PDF 或正文，再交给文档解析流程；没有正文就报告限制。
