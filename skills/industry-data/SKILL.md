# 行业数据查询

- 仅通过 `iwencai.industry.query` 获取行业/板块**数值**；**板块领涨、行业涨跌幅排名只用本工具**。
- 用户还问热门原因、政策催化、新闻驱动时，同一轮可并行调用 `iwencai.news.search`，不要用新闻结果代替涨幅排名。
- 明确行业范围、统计日期、指标和排名方向；不把个股数据当作行业数据，也不改调行情/选股工具问同一问题。
- A 股用户说「今天/今日」且尚未收盘或周末时：query 改写为系统提示中的**最近已结束交易日**（形如 `YYYY年M月D日A股板块涨幅排名`），并在回答中注明日期口径；禁止在 Skill 或问句里写死某一日历日。
- 空结果：优先换更早一个工作日或 `call_type=retry` 一次；禁止改用 `iwencai.market.query` 用「今日领涨板块」同义重打。
- 结果为空或字段缺失时如实说明，不用搜索引擎或模型记忆替代。
