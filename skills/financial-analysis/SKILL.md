# 多源综合分析

- 适用：多公司对比、多指标拆解、因果/驱动、把问财、年报、新闻、FAQ 等**多于一路**结果合成一份回答。
- 不适用：闲聊、澄清、单公司单指标直查（工具结果已足够直接回答）。
- 流程：先按其它 skill 并行检索 → 收齐本轮 tool/result → 若当前工具列表有 `finalign_analyze`，**只调用一次**（材料可留空，系统会从本轮工具结果收集），把返回正文作为最终回答；**没有该工具时不要编造调用，直接根据已检索结果作答**。
- 只根据工具结果分析，禁止用模型记忆补数字或改数量级。
- 某路空结果或失败时，让分析工具如实写缺口，不要改调不相关工具凑数。
- 本地 finalign 未启动时分析工具不会出现在列表里，也不回退 DeepSeek；主路径根据已检索结果直接作答。
