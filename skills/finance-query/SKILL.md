# 财务数据查询

- 仅通过 `iwencai.finance.query` 获取财务指标事实，不使用模型记忆补齐数值。
- 写明公司、指标与报告期；**期间只认指标字段名中的 `[YYYYMMDD]`**（如 `营业收入(累计)[20251231]`），`报告期截止日*` 可忽略、不得用来否定指标值。
- 币种以工具返回为准，不得按上市地或股票代码后缀臆测。
- 空结果如实报告缺口，不改查无关年份凑数。
