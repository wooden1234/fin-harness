# 财报对比 使用指南

## 技能概述

本技能用于多实体已披露财务对比，支持：

- **完整财年 / 财季对比**：营业收入、归母净利润等
- **口径说明**：财年截止日、币种（有则写、无则未知）
- **公告出处（可选）**：用户要公告/年报链接时，再用短词检索公告标题
- **超预期场景**：再补一致预期或评级（`query_iwencai_rating`）

**工具边界（源头规则，勿混用）：**

| 目标 | 工具 | 不要做 |
|------|------|--------|
| 营收、净利、ROE 等数值 | `query_iwencai_finance` | 不要用公告搜索凑数字 |
| 公告标题/链接/披露文件 | `search_iwencai_announcement`（短查询） | 不要把指标名塞进公告 query |

`search_iwencai_announcement` 检的是**公告文档标题/正文**，不是结构化财务字段。把「营业收入」「归母净利润」「截至…止年度」叠进 query，会显著降低命中（常见 `total=0`）。

数值主路径始终是 `query_iwencai_finance`（market 预算约 4 次/任务）。数值已齐即可成稿；不为对齐财年或币种反复检索。同族预算耗尽后禁止继续同族空转，立刻用已有 Evidence 成稿。

**完整财年读数字：** 只用指标名含 **「累计」** 且带 `[YYYYMMDD]` 的字段（如 `营业收入(累计)[20251231]`）。**禁止**用 `单季度`/`单季` 或 `最新价`/`涨跌幅` 填「最近完整财年」主表。

## 核心处理流程

### 步骤 0: 规划 todos（调工具前）

先写 3–5 条可执行 todos，再查数。每条须含实体或年结口径、指标、工具主路径；禁止「查询数据」「整理答案」这类空泛条目。典型拆分：

1. 确认各公司最近完整财年截止日（按年结分列，勿三家同一报告期）
2. 同口径合查 / 异年结分查 `query_iwencai_finance`（累计+`[YYYYMMDD]`）
3. 用户要来源时短查公告或 Web 出处（不覆盖主表数字）
4. 表格+结论成稿；年结/币种差异写入 caveat；空字段写 gaps 并停

空表、年结错位或阶段变化时更新对应 todo 状态后再纠错重查。

### 步骤 1: 定实体、指标与各自最近完整财年

- 从用户问题识别比较实体、指标（如营业收入、归母净利润）。
- 「最近完整财年」= **各公司财年截止日 ≤ as_of 的最近一个已结束完整财年**，按年结分别取值；禁止为对齐把 3 月年结压回更早一年，禁止用中期填主表。
- 例（as_of=2026-08-04）：腾讯/美团（12-31 年结）→ **2025-12-31**；阿里巴巴（3-31 年结）→ **2026-03-31**（不是 2025-03-31）；美股常见：苹果约 **2025-09** 财年末、微软约 **2026-06-30**、谷歌/Alphabet 约 **2025-12-31**——禁止一次合查糊成同一 `[YYYYMMDD]`。
- 用户指定年份时按其要求。

### 步骤 2: Query 改写

**财务数值（必做）**：改写为 `query_iwencai_finance` 问句。**同口径年结多实体必须合查为 1 次**（禁止一司一查）；**异年结必须按各自截止日分开查**，不要并进「最近完整财年」一次合查。三家中概对比典型写法：腾讯+美团合查 1 次 + 阿里单独 1 次；苹果/微软/谷歌按 9 月/6 月/12 月年结分开，最多再留 1 次纠错。不要用通用 `query_iwencai` 替代。空表时按正确年结重查财务，**禁止用网页金额填主表**。

**公告出处（仅当用户明确要公告/年报/出处链接时）**：每实体最多 1 次，query **只保留**「公司 + 年份/财年 + 业绩公告|年度业绩」，控制在约 6–12 个汉字词内。

**公告 query 硬性禁止：**

- 禁止写入指标名：营业收入、归母净利润、净利率等
- 禁止超长正式截止日串：如「截至2025年12月31日止年度」「全年业绩公告营业收入…」
- 禁止一次塞多个指标；公告工具不负责出表数字

**改写规则（财务问句）：**

- 12-31 年结：写「公司 + {as_of.year-1}年全年 + 指标」，核验返回字段名含该年-12-31（如 `[20251231]`），**不要**用 `报告期截止日` 单元格否决结果
- 3-31 年结：若 as_of ≥ 当年-03-31，写「公司 + 截至{as_of.year}-03-31完整财年 + 指标」或「公司 + {as_of.year}财年 + 指标」；否则用上一年-03-31
- 保留用户核心指标；口语改为标准财务术语
- 不自行拼接季度数据凑自然年

**常用查询改写示例（as_of=2026-08-04）：**

| 用户意图 | 财务问句（主路径） | 公告检索（仅要出处时） |
|---------|-------------------|------------------------|
| 腾讯收入与归母净利 | 腾讯控股2025年全年营业收入和归母净利润 | 腾讯 2025 年度业绩 |
| 美团收入与归母净利 | 美团2025年全年营业收入和归母净利润 | 美团 2025 年度业绩 |
| 阿里（3 月年结，取最新） | 阿里巴巴截至2026-03-31完整财年营业收入和归母净利润 | 阿里巴巴 2026财年 业绩 |
| 腾讯+美团合查 | 腾讯控股、美团2025年完整年度营业收入和归母净利润 | 各实体短词各 1 次 |

**反例（会导致公告 `total=0`，禁止再用）：**

- `美团 截至2025年12月31日止年度 全年业绩公告 营业收入 归母净利润`

### 步骤 3: 调用与核对

1. **先**按合查规则调用 `query_iwencai_finance`（同口径合并、异年结分开）取各公司最近完整财年数值入主表（阿里必须查到 2026-03-31 口径，不得用 2025-03-31 冒充最新）。
2. 用返回的行数据核对实体、指标、期间、数值：
   - **期间唯一依据 = 指标字段名里的 `[YYYYMMDD]`**（如 `营业收入(累计)[20251231]`、`归母净利润(累计)[20251231]`）。主表截止日按此日期写。
   - **`报告期截止日*` 单元格可忽略**：常与指标口径不一致或错位，不得因该字段怪异而判定无效、不得因此重查或改查 Web。
   - 空数组、`(0)`、仅行情（只有最新价/涨跌幅）、实体不匹配 → 不作财务证据
   - 「累计」+ 指标名截止日为完整财年末（如 12-31 / 03-31 / 09-30 / 06-30）→ 可作该完整财年，注明字段名
   - 返回裸数字且无「人民币/港元/美元」等文字或字段单位 → 币种视为未知，不得按股票代码反推
3. **仅当目标指标字段缺失或 `[YYYYMMDD]` 不是目标财年**时，对该实体按正确截止日重查 **1 次**；仍不对 → 写缺口。禁止因为 `报告期截止日` 看着不对就重查或转 Web。
4. 仅当用户要公告/出处时：用**短词**调 `search_iwencai_announcement`；`total=0` / 空 `content_data` → **立即停用该工具**，写 gaps「公告未命中」，改用已有财务 Evidence 成稿，禁止加长 query 重试、禁止改查其他年份。
5. 公告有命中时，只把标题/链接/披露日写入出处说明或 gaps；**主表数字仍以 `query_iwencai_finance` 为准**，不要从公告摘要里手抄金额覆盖主表，除非摘要中指标、截止日、币种均明确且与财务结果一致。

### 步骤 4: 空数据与停止

| 情况 | 动作 |
|------|------|
| 各实体已有带目标 `[YYYYMMDD]` 的营收/归母净利字段 | **直接成稿**；不为核对 `报告期截止日` 去 Web |
| 财务缺失（无目标指标字段） | 对该实体 `search_web`/PDF 最多 1 次；串台或空结果丢弃 |
| 公告 `total=0` | 停用公告工具，gaps 记录，不重试 |
| 涉及“超预期” | 补 `query_iwencai_rating`，每实体最多 1 次 |

任一工具连续 2 次对同一实体返回空/无效后，立即停止该实体补查，进入步骤 5。

### 步骤 5: 成稿回答（写入 MainAgentResponse）

| 字段 | 写法 |
|------|------|
| `heading` | 「结论」或留空；禁止「主表：」 |
| `statements`（fact/inference） | 1 句盈亏/格局，**不复述表内金额** |
| `tables[0].title` | 自然名，如「最近一个完整财年财务对比」；禁止「主表：」和「A vs B」第二标题 |
| `statements`（`statement_type=caveat`） | 表下口径差异一两句（财年/币种/指标名） |

渲染顺序：结论陈述 → 表格 → caveat。

主表放各公司最近完整财年已核验财务数值；列清各自截止日与币种（未知则写未知）；不换算统一、不按代码猜币种；财年窗口不同时不做金额排序，并在 caveat 点明（如阿里 3/31 vs 腾讯/美团 12/31）。

## 注意事项

- 上市交易币种 ≠ 财报列报币种；不得用 `.HK`/`.N`/`.SZ` 等代码后缀反推币种。
- 问财裸数字常无币种后缀 → 主表写「未知」，勿臆测。
- 归母净利润口径可能因公司披露用语不同而有差异；沿用证据原文用语。
- 追问放入 follow_ups，正文不写「需要我继续」。
- 数据来源标明（问财财务 / 公告 / Web），不得把未命中的公告检索标成「已引用官方数据」。
